# Horizon Education — خطة التنفيذ

## 1. خريطة الموقع
- العامة: الرئيسية، الكورسات، تفاصيل كورس، المدرسين، عن المنصة، FAQ، الخصوصية، الشروط، تواصل، دخول، تسجيل طالب، استعادة كلمة المرور، 403، 404.
- Admin: Dashboard، المدرسون، الطلاب، الكورسات، المدفوعات، الفواتير، التقارير، وسائل الدفع، التصنيفات التعليمية، Audit Logs.
- Teacher: Dashboard، الشابترات، الحصص، الفيديوهات، المرفقات، أكواد الوصول، الواجبات، الاختبارات، الطلاب، المستحقات.
- Student: Dashboard، كورساتي، تفعيل كود، مشاهدة حصة، الواجبات، الاختبارات، الدرجات، المدفوعات، الملف الشخصي.

## 2. User Flows
### الأدمن
إنشاء مدرس → ربطه بكورس/مراحل → متابعة الطلاب → تسجيل دفعة → إصدار فاتورة → مراجعة التقارير.
### المدرس
تسجيل الدخول → إنشاء Chapter → إنشاء Lesson → رفع فيديو/مرفقات → توليد أكواد → إنشاء اختبار/واجب → مراجعة نتائج الطلاب.
### الطالب
تسجيل حساب → دخول → اختيار كورس → دفع خارج/داخل الإدارة → إدخال كود → مشاهدة الحصة → حل اختبار/واجب → متابعة الدرجات.

## 3. Wireframes مبدئية
- Home: Hero + مزايا + كورسات + CTA.
- Login: كارت مركزي + Validation.
- Dashboards: Sidebar + Cards + Table + Notifications.

## 4. Design System
ألوان العلامة: Ember Brown #43251E، Maple Red #68160D، Horizon Orange #CF4116، Stone Taupe #AB9A90، Paper Cream #EEDCC7. RTL، Radius كبير، Cards، Tables، Badges.

## 5. قاعدة البيانات
استخدم schema.sql المرفق كنقطة بداية. أضف migrations لاحقًا بدل التعديل اليدوي.

## 6. Backend/API
- POST /api/auth/login
- POST /api/courses
- POST /api/payments
- POST /api/codes/activate
لاحقًا: CRUD كامل للمدرسين، الطلاب، الشابترات، الحصص، الاختبارات، الواجبات، التقارير.

## 7. الأمان
RBAC على السيرفر والواجهة، Hash passwords، JWT/httpOnly cookies لاحقًا، Zod server validation، Transactions للمدفوعات والأكواد، Audit Logs، Soft Delete.

## 8. مراحل التنفيذ
1. الواجهات الأساسية واللوحات.
2. Authentication/RBAC.
3. إدارة المدرسين والكورسات.
4. الشابترات والحصص والمرفقات.
5. الأكواد وتفعيل الوصول.
6. المدفوعات والفواتير والتقارير.
7. الاختبارات والواجبات.
8. الاختبارات والـ hardening.
