# Horizon Education

منصة تعليم إلكتروني عربية RTL مبنية بـ Next.js App Router + TypeScript + Tailwind CSS + React Hook Form/Zod + MySQL.

## التشغيل
```bash
npm install
cp .env.example .env
npm run dev
```

## الصفحات المنفذة كبداية
- `/` الصفحة الرئيسية
- `/login` تسجيل الدخول
- `/register` تسجيل طالب
- `/admin` لوحة الأدمن
- `/teacher` لوحة المدرس
- `/student` لوحة الطالب

## API Starter
- `POST /api/auth/login`
- `POST /api/courses`
- `POST /api/payments`
- `POST /api/codes/activate`

## ملاحظات مهمة
هذا إصدار MVP starter سهل التنفيذ، وليس منصة إنتاج مكتملة. يلزم استكمال المصادقة بالكوكيز الآمنة، Middleware للصلاحيات، CRUD الكامل، PDF invoices، uploads، tests، وdeployment على النطاق.
